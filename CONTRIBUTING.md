# Как внести свой вклад

Спасибо за интерес к проекту ErgoAssistant! 

## Установка
1. Установите [Ollama](https://ollama.com/) и скачайте модель `llama3.2`.
2. Клонируйте репозиторий.
3. Установите зависимости: `pip install -r requirements.txt`.

## Запуск
Запустите локальный сервер Ollama и выполните `python main.py`.
