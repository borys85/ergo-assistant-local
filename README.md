# 🧘‍♂️ ErgoAssistant: Локальный гид по эргономике для разработчиков

Интеллектуальный инструмент для сохранения здоровья глаз, спины и общей продуктивности при интенсивной работе за компьютером. Решение основано на проверенных методиках (правило 20-20-20, микро-разминки) и генерируется с помощью локальной языковой модели (LLM).

## 📋 Базовый протокол: «Эргономичный час»

Стандартный цикл работы, рекомендованный системой для поддержания высокой концентрации без ущерба для здоровья:

1. **0–20 мин:** Фаза глубокой фокусировки.
   *   *Контроль:* Спина прямая, верхняя кромка монитора на уровне глаз.
2. **20-я минута:** Оптическая разгрузка (Правило 20-20-20).
   *   *Действие:* Переведите взгляд на объект, находящийся в 6 метрах от вас, на 20 секунд.
   *   *Важно:* Интенсивно моргайте для увлажнения роговицы.
3. **20–40 мин:** Продолжение работы.
   *   *Контроль:* Локти под углом 90°, запястья не находятся в напряжении («не висят в воздухе»).
4. **40-я минута:** Шейная мобилизация.
   *   *Действие:* Плавные наклоны головы влево и вправо (по 5 секунд). Избегайте резких движений.
5. **40–60 мин:** Завершение текущего спринта задач.
6. **60-я минута:** Полный физический перезагруз.
   *   *Действие:* Встаньте из-за стола, выполните потягивания вверх, сделайте серию глубоких вдохов и выдохов.

## 💡 Рекомендации системы

*   📱 **Автоматизация контроля:** Используйте специализированные утилиты (например, *Stretchly*, *Eye Leo* или встроенные таймеры ОС) для напоминаний.
*   👁️ **Профилактика сухости:** Во время пауз сознательно контролируйте частоту моргания.
*   🦴 **Реакция на дискомфорт:** При возникновении острой боли немедленно прекратите работу на 5–10 минут и выполните растяжку грудного отдела позвоночника.
